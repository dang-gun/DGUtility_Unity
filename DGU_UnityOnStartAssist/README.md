# DGU_UnityOnStartAssist
유니티에서 Start 처리를 도와주는 유틸리티 입니다.


MonoBehaviour를 상속받는 스크립트의 경우 Awake가 처리되야 개체가 생성된다.  
Awake가 호출되기 전에 초기화 정보를 미리 넣는 경우 그때그때 처리해야 하는 문제가 있다.  
이 유틸은 Awake가 종료되고 나서 호출되는 Start에서 호출하여 이러한 처리를 공통화해준다.  
Start가 실행전이면 Start가 호출될때가지 대기하고 이미 Start가 호출되었으면 바로 실행된다.  
이 개체는 한번 동작하면 필요없으므로 적절한 타이밍에 제거하는 것이 좋다.
